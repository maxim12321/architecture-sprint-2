# pymongo-api

## kazhem/pymongo_api:1.0.0

В задании указано, что обязательно использовать версию `1.0.0`, однако в ней есть строчка, которая не работает
при использовании нескольких инстансов `router` для MongoDB. Версия `1.0.1`, которая использована в решении,
должна собираться из локальных файликов, которые отличаются ровно одной закомментированной строчкой в `app.py`:
```python
# "mongo_address": client.address,
```

Без этого не получилось бы использовать правильный вариант строки подключения к MongoDB:
```
MONGODB_URL: "mongodb://router-1,router-2,router-3"
```

## Схема полного решения

Финальная схема находится в файле `task1.drawio`, а также доступна на гугл диске:
https://drive.google.com/file/d/1ROyjfqXABCjTrGL3CSmyw_c8W48x7OGb/view?usp=sharing

## Как запустить

Переходим в директорию с финальной версией проекта
```shell
cd sharding-repl-cache
```

Запускаем докер
```shell
docker compose up -d
```

Настраиваем шардирование в MongoDB
```shell
./scripts/sharding-init.sh
```

Заполняем mongodb данными
```shell
./scripts/mongo-init.sh
```

## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080
